## 📖 Sobre el Proyecto

**Punto y Aparte Muebles** es el proyecto final del curso de **Desarrollo Web en CoderHouse**. Se trata de un sitio web estático para una tienda de muebles infantiles con filosofía **Montessori**: jugueteros, cómodas, organizadores y más.

El objetivo del proyecto fue demostrar el dominio de las tecnologías web modernas —HTML, CSS/SCSS y Bootstrap— construyendo un sitio completo, responsive y desplegado en producción.

> 🌐 **Demo en vivo:** [punto-y-aparte-muebles.vercel.app](https://punto-y-aparte-muebles.vercel.app/)

---

## ✨ Características del Sitio

- 🛋️ **Catálogo de productos** con imágenes, descripciones y precios actualizados
- 📱 **Diseño completamente responsive** para móvil, tablet y escritorio
- 💬 **Botón flotante de WhatsApp** para consultas y pedidos directos
- 🎉 **Popup promocional automático** con ofertas y métodos de pago
- 📩 **Formulario de contacto funcional** con envío de email via PHP
- 🧭 **Navegación multi-página** fluida con header y footer consistentes
- 🎨 **Estilos personalizados con SCSS** y variables de diseño reutilizables

## 🚀 Instalación y Uso Local

### Requisitos
- Servidor web con PHP (ej: [XAMPP](https://www.apachefriends.org/) o [Laragon](https://laragon.org/))
- Git

```bash
# 1. Clonar el repositorio
git clone https://github.com/GustavoBaranda/Punto-y-Aparte-Muebles.git

# 2. Mover la carpeta al directorio del servidor local
# Ejemplo con XAMPP → C:/xampp/htdocs/Punto-y-Aparte-Muebles

# 3. Iniciar Apache desde el panel de XAMPP

# 4. Abrir en el navegador
http://localhost/Punto-y-Aparte-Muebles/
```

> **Nota:** Para ver el sitio sin PHP, podés abrir `index.html` directamente en el navegador. El formulario de contacto requiere servidor para funcionar.
